# AI Resume Screener

An AI-assisted candidate shortlisting system built with Java 17 and Spring Boot.

## Run

```bash
./mvnw spring-boot:run
```

Open `http://localhost:8080`.

## Features

- PDF, DOC, and DOCX resume upload
- Predefined and custom job roles
- Apache Tika document text extraction
- Dictionary-based skill extraction
- Weighted candidate ranking
